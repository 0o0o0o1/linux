# 파일 탐색 (find)

## 1. find란?

find는 이름 그대로 파일을 탐색하는 명령어로,  
지정한 경로부터 시작하여 조건(표현식)을 만족하는 파일을 검색한다.

---

## 2. 기본 사용법

```bash
find [옵션] [탐색 시작 경로] [표현식]
```

- 지정한 경로부터 하위 디렉터리를 모두 탐색
- 조건에 맞는 파일의 경로를 출력

---

## 3. 주요 옵션

| 옵션 | 설명 |
|------|------|
| -L | 심볼릭 링크 따라가기 |
| -H | 명령행 인자로 받은 링크만 따라가기 |
| -D | 디버그 정보 출력 |
| -O[level] | 최적화 수준 설정 |

---

## 4. 자주 사용하는 표현식

| 표현식 | 설명 |
|--------|------|
| -name | 파일 이름 검색 |
| -user | 사용자 기준 검색 |
| -group | 그룹 기준 검색 |
| -uid | UID 기준 검색 |
| -gid | GID 기준 검색 |
| -perm | 권한 기준 검색 |
| -type | 파일 종류 (f: 파일, d: 디렉터리) |
| -maxdepth | 최대 탐색 깊이 |
| -mindepth | 최소 탐색 깊이 |

---

## 5. 기본 실습

### 특정 파일 검색

```bash
$ find . -name 'file1'
```

```bash
./test/file1
```

- `.` : 현재 디렉터리부터 시작  
- `-name 'file1'` : file1 이름을 가진 파일 검색  
- 결과: 해당 파일의 경로 출력

---

## 6. 와일드카드 사용

```bash
$ find . -name '*.txt'
```

- `*` : 모든 문자열을 의미  
- `.txt` 확장자를 가진 파일 검색

---

## 7. 핵심 정리

- find는 파일을 조건에 따라 탐색하는 명령어이다.
- 시작 경로부터 모든 하위 디렉터리를 탐색한다.
- 다양한 표현식을 조합하여 정밀한 검색이 가능하다.
