# 파일 링크 (Link)

## 1. 링크 파일이란?

링크 파일(Link File)은 특정 파일을 참조하여 접근할 수 있도록 연결된 파일이다.  
Windows의 바로가기와 유사한 개념이다.

---

## 2. 리눅스 파일 시스템과 inode

리눅스는 파일을 inode라는 메타데이터로 관리한다.  
각 파일은 고유한 inode를 가진다.

### inode에 포함된 정보

- inode 번호
- 파일 모드 (권한)
- 링크 개수
- 소유자 및 그룹 ID
- 파일 크기
- 접근/수정 시간
- 데이터 저장 위치

---

## 3. 하드 링크 (Hard Link)

하드 링크는 원본 파일의 inode를 직접 공유하는 방식이다.

- 원본 파일과 동일한 inode 사용
- 사실상 동일한 파일
- 링크 개수 증가
- 원본 삭제해도 데이터 유지됨

### 실습

```bash
$ ln file1 hardlink_file
```

```bash
$ ls -ali
```

```bash
1970324837198326 file1
1970324837198326 hardlink_file
```

- inode 번호 동일
- 링크 개수 증가 (2)

---

## 4. 심볼릭 링크 (Symbolic Link)

심볼릭 링크는 다른 파일을 경로로 참조하는 방식이다.

- 새로운 inode 생성
- 원본 경로를 가리킴
- 원본 삭제 시 접근 불가

### 실습

```bash
$ ln -s file1 symlink_file1
```

```bash
$ ls -ali
```

```bash
1970324837198326 file1
4222124650906279 symlink_file1
```

- inode 번호 다름

---

## 5. ln 명령어

```bash
ln [옵션] [원본파일] [링크파일]
```

### 주요 옵션

| 옵션 | 설명 |
|------|------|
| -s | 심볼릭 링크 생성 |
| -f | 기존 파일 덮어쓰기 |
| -n | 링크 대상 덮어쓰기 |

---

## 6. 핵심 정리

- 하드 링크: inode 공유, 동일 파일
- 심볼릭 링크: 경로 참조, 별도 파일
- inode로 파일 식별
- 링크 개수로 연결 상태 확인 가능
