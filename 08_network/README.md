# 네트워크(Network)

## 1. 네트워크란?

네트워크(Network)는 **그물(Net) + 일(Work)** 의 합성어로, 2개 이상의 컴퓨터들이 서로 통신하기 위해 필요한 모든 것들을 통칭하는 표현이다.

네트워크는 계층 구조를 가지고 있으며 각 계층은 자신의 바로 아래 계층과만 통신할 수 있다. 이때 각 계층에서 사용하는 통신 규약을 **프로토콜(Protocol)** 이라 부른다.

데이터를 전송할 때는 아래 계층으로 내려가면서 필요한 프로토콜 헤더가 추가되고, 수신 측에서는 위 계층으로 올라가면서 헤더가 제거된다. 이를 캡슐화(Encapsulation)와 역캡슐화(Decapsulation)라고 한다.

---

## 2. 네트워크 계층 구조

### 물리 계층 (Physical Layer)

0과 1의 전기적 신호가 케이블을 통해 전달되는 과정이다.

대표 예시:

- UTP 케이블
- 광케이블
- 허브(Hub)

---

### 데이터 링크 계층 (Data Link Layer)

물리 계층을 통해 전달되는 데이터가 안전하게 전송될 수 있도록 한다.

대표 예시:

- Ethernet
- MAC Address
- Switch

---

### 네트워크 계층 (Network Layer)

수신자와 송신자를 구분하기 위해 IP 주소 등을 포함한 패킷(Packet)을 생성한다.

라우터는 이 정보를 바탕으로 목적지까지 최적의 경로를 선택하여 패킷을 전달한다.

대표 예시:

- IPv4
- IPv6
- Router

---

### 전송 계층 (Transport Layer)

수신자와 송신자가 올바른 데이터를 주고받을 수 있도록 한다.

포트 정보를 포함한 세그먼트(Segment)를 생성하며 오류 검출, 오류 복구, 흐름 제어 등을 수행한다.

대표 예시:

- TCP
- UDP
- Port

---

### 세션 계층 (Session Layer)

애플리케이션 간 통신 연결을 관리하는 계층이다.

세션(Session)은 송신자와 수신자 사이의 연결 상태를 의미하며, 데이터 통신을 동기화하고 오류 발생 시 복구를 지원한다.

---

### 표현 계층 (Presentation Layer)

송수신 과정에서 사용하는 데이터 형식을 통일하는 계층이다.

운영체제나 프로그램에 따라 발생하는 데이터 형식 차이를 해결하기 위해 데이터를 변환한다.

대표 예시:

- 문자 인코딩
- 데이터 압축
- 암호화

---

### 응용 계층 (Application Layer)

사용자에게 네트워크 서비스를 제공하는 계층이다.

사용자가 전송하려는 데이터를 해당 프로토콜 형식에 맞게 변환하여 전송한다.

대표 예시:

- HTTP
- HTTPS
- FTP
- SSH
- DNS

---

## 3. 핵심 정리

- 네트워크는 여러 컴퓨터가 통신하기 위한 기술의 집합이다.
- 각 계층은 바로 아래 계층과만 통신한다.
- 계층 간 통신 규칙을 프로토콜이라고 한다.
- 데이터를 전송할 때는 헤더가 추가되고 수신 시 제거된다.
- TCP/IP 및 OSI 모델은 네트워크 계층 구조를 설명하기 위해 사용된다.
