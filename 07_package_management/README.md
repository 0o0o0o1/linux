# 패키지 관리

## 1. 패키지란?

리눅스 패키지(Linux Package)란 프로그램을 실행하기 위해 필요한 파일들을 하나로 묶어둔 설치 파일이다.

패키지는 크게 다음 2가지로 구분된다.

- 소스 패키지(Source Package)
- 바이너리 패키지(Binary Package)

---

## 2. 소스 패키지와 바이너리 패키지

### 소스 패키지(Source Package)

소스코드가 포함된 패키지이다.  
사용자가 직접 컴파일하여 설치한다.

### 장점

- 소스코드를 자유롭게 수정 가능
- 원하는 형태로 프로그램 개조 가능
- 시스템 환경에 맞춘 최적화 가능

### 단점

- 직접 컴파일해야 하므로 설치 시간이 오래 걸림
- 컴파일 과정 중 오류가 발생할 수 있음
- 의존성을 직접 해결해야 하는 경우가 있음

---

### 바이너리 패키지(Binary Package)

이미 컴파일된 실행 파일(Binary)을 포함한 패키지이다.

### 장점

- 바로 설치 가능
- 설치 시간이 짧음
- 오류 발생 가능성이 낮음

### 단점

- 필요한 의존성 패키지가 없으면 실행 불가능
- 사용자가 직접 수정하기 어려움

---

## 3. 패키지 의존성 (Package Dependency)

프로그램이 실행되기 위해 다른 패키지가 필요한 상황을 의미한다.

예를 들어 htop은 ncurses 라이브러리를 사용한다.

따라서 ncurses 관련 패키지가 설치되어 있지 않으면 htop은 정상적으로 동작할 수 없다.

이를 패키지 의존성(Package Dependency)이라고 한다.

---

## 4. 패키지 관리자 (Package Manager)

사용자가 모든 의존성을 직접 관리하기는 어렵기 때문에 리눅스는 패키지 관리자(Package Manager)를 제공한다.

패키지 관리자는:

- 패키지 설치
- 패키지 제거
- 패키지 업데이트
- 의존성 해결

등을 자동으로 수행한다.

대부분의 리눅스 배포판은 바이너리 패키지와 패키지 관리자를 사용한다.

---

## 5. 저수준 패키지 관리 도구

저수준 패키지 관리 도구(Low Level Package Tool)는 패키지를 직접 설치하거나 제거할 때 사용한다.

패키지 간 의존성을 자동으로 해결하지 않는다.

### Debian 계열

| 도구 | 설명 |
|------|------|
| dpkg | .deb 패키지 관리 |

### Red Hat 계열

| 도구 | 설명 |
|------|------|
| rpm | .rpm 패키지 관리 |

---

## 6. 고수준 패키지 관리 도구

고수준 패키지 관리 도구(High Level Package Tool)는 패키지 의존성을 자동으로 해결한다.

일반적으로 사용자는 고수준 패키지 관리 도구를 사용한다.

### Debian 계열

| 도구 | 설명 |
|------|------|
| apt | 패키지 설치 및 관리 |
| apt-get | apt 기반 패키지 관리 |

### Red Hat 계열

| 도구 | 설명 |
|------|------|
| yum | 패키지 설치 및 관리 |
| dnf | yum 개선 버전 |

---

## 7. 패키지 설치 예시

### apt 사용

```bash
$ sudo apt install htop
```

- htop 패키지를 설치한다.
- 필요한 의존성 패키지도 함께 설치된다.

---

### rpm 사용

```bash
$ sudo rpm -ivh test.rpm
```

- rpm 패키지를 직접 설치한다.
- 의존성은 자동으로 해결되지 않는다.

---

### dpkg 사용

```bash
$ sudo dpkg -i test.deb
```

- deb 패키지를 직접 설치한다.
- 의존성 오류가 발생할 수 있다.

---

## 8. 핵심 정리

- 패키지는 프로그램 설치 파일이다.
- 소스 패키지는 직접 컴파일한다.
- 바이너리 패키지는 이미 컴파일되어 있다.
- 패키지 의존성은 다른 패키지가 필요한 상황이다.
- 패키지 관리자는 의존성을 자동으로 관리한다.
- 일반적으로 apt, yum, dnf 같은 고수준 패키지 관리 도구를 사용한다.
