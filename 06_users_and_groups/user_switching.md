# 유저 변경

## 1. 유저 변경 (su)

su는 **substitute user**의 약자로 다른 유저로 전환할 때 사용한다.  
사용자를 지정하지 않는 경우 root를 의미한다.

```bash
su [옵션] [유저이름]
```

### 주요 옵션

| 옵션 | 설명 |
|------|------|
| -c [명령어] | 지정한 명령 실행 |
| - / -l | 로그인 셸로 전환 |
| -s [셸] | 사용할 셸 지정 |

---

## 2. 비밀번호 설정

계정에 비밀번호가 없다면 설정해야 한다.

```bash
$ sudo passwd test
```

---

## 3. 사용자 전환

### 일반 전환

```bash
$ su test
Password:
```

- test 계정으로 전환된다.
- 현재 디렉터리와 일부 환경 변수는 유지된다.

---

### 로그인 셸 전환

```bash
$ su - test
Password:
```

```bash
$ pwd
/home/test
```

- `-` 또는 `-l` 옵션을 사용하면 홈 디렉터리까지 변경된다.
- 로그인 환경으로 전환된다.

---

## 4. sudo

sudo는 **substitute user do**의 약자로 다른 사용자의 권한을 빌려 명령을 실행한다.  
사용자를 지정하지 않으면 기본적으로 root 권한으로 실행된다.

```bash
sudo [옵션] [명령어]
```

### 주요 옵션

| 옵션 | 설명 |
|------|------|
| -b | 백그라운드 실행 |
| -C [fd] | 특정 fd 유지 |
| -e | 파일 편집 |
| -g [GID/그룹] | 그룹 지정 |
| -u [UID/유저] | 사용자 지정 |
| -s | 셸 실행 |
| -i | 로그인 셸 실행 |

---

## 5. root 셸 실행

```bash
$ sudo -s
```

```bash
root@hostname:/home/user#
```

- root 권한 셸을 실행한다.

---

## 6. 관리자 권한 파일 접근

### 일반 사용자 접근

```bash
$ cat /etc/shadow
```

```bash
cat: /etc/shadow: Permission denied
```

- 일반 사용자는 `/etc/shadow`를 읽을 수 없다.

---

### sudo 사용

```bash
$ sudo cat /etc/shadow
```

```bash
root:*:19000:0:99999:7:::
test:$6$abc123...:19000:0:99999:7:::
```

- sudo를 사용하면 관리자 권한으로 명령을 실행할 수 있다.

---

## 7. 핵심 정리

- su: 사용자 전환
- su - : 로그인 환경으로 전환
- sudo: 다른 사용자 권한으로 명령 실행
- 기본적으로 sudo는 root 권한 사용
