# 권한 관리

## 1. 유저와 그룹

리눅스는 **유저(user)**와 **그룹(group)** 기반으로 권한을 관리한다.

- 하나의 유저는 하나의 기본 그룹을 가진다.
- 하나의 유저는 여러 개의 그룹에 속할 수 있다.
- 그룹은 특정 권한을 공유하기 위한 사용자 집합이다.

---

## 2. 계정 정보 파일

### /etc/passwd

유저 정보를 저장하는 파일이다.

```bash
$ cat /etc/passwd
```

```bash
root:x:0:0:root:/root:/bin/bash
user:x:1000:1000:user:/home/user:/bin/bash
```

구조:
```
이름 : 암호 : UID : GID : 추가정보 : 홈 디렉터리 : 기본 셸
```

---

### /etc/shadow

암호 및 계정 정보를 저장하는 파일이다.  
root 권한만 접근 가능하다.

```bash
$ sudo cat /etc/shadow
```

```bash
root:*:19000:0:99999:7:::
user:$6$abc123...:19000:0:99999:7:::
```

구조:
```
이름 : 암호화 값 : 수정일 : 최소기간 : 최대기간 : 경고기간 : 만기일 : 비활성기간 : reserved
```

---

### /etc/group

그룹 정보를 저장한다.

```bash
$ cat /etc/group
```

```bash
root:x:0:
user:x:1000:
```

구조:
```
이름 : 암호 : GID : 멤버
```

---

### /etc/gshadow

그룹 암호 및 관리자 정보를 저장한다.

```bash
$ sudo cat /etc/gshadow
```

```bash
root:*::
user:*::
```

구조:
```
이름 : 암호 : 관리자 : 멤버
```

---

## 3. root와 sudo

- root는 최고 권한을 가진 관리자 계정이다.
- 시스템 설정 변경, 계정 관리 등이 가능하다.

```bash
$ sudo 명령어
```

- sudo는 root 권한으로 명령을 실행한다.

---

## 4. 파일 권한

리눅스는 파일 권한을 다음 3가지 주체로 나눈다.

| 구분 | 의미 |
|------|------|
| u | 사용자 (owner) |
| g | 그룹 |
| o | 기타 사용자 |

각 주체는 다음 권한을 가진다.

| 권한 | 의미 | 값 |
|------|------|----|
| r | 읽기 | 4 |
| w | 쓰기 | 2 |
| x | 실행 | 1 |

---

## 5. 권한 조합

각 권한은 독립적으로 조합 가능하다.

```bash
rwx = 7
rw- = 6
r-- = 4
```

총 9개의 권한 비트로 구성된다.

---

## 6. 특수 권한

### setuid / setgid

- 실행 시 파일 소유자의 권한으로 실행됨

| 권한 | 값 |
|------|----|
| setuid | 4 |
| setgid | 2 |

---

### sticky bit

- 디렉터리에서 파일 삭제 제한

| 권한 | 값 |
|------|----|
| sticky bit | 1 |

- 파일 생성은 가능하지만 삭제는 소유자와 root만 가능

---

## 7. 핵심 정리

- 리눅스는 유저와 그룹 기반 권한 관리
- 파일 권한은 u / g / o로 구분
- r, w, x 조합으로 권한 구성
- 숫자(4,2,1)로 표현 가능
- 특수 권한(setuid, setgid, sticky bit) 존재
